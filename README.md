# 📖 Atividade 02 - HTML
Nesta atividade fomos instruídos a criar um site sobre um tema de livre escolha, onde tivemos que montar o site com imagens, listas e sub-páginas.

## 🤔 O que foi trabalhado?
Foi trabalhado nessa atividade nossa capacidade de montar um site bom utilizando apenas o HTML clássico. O desáfio principal era fazer o site ficar apresentável sem a utilização de CSS.
